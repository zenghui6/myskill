# 开发日志 · 2026-10-15

## 11:52 · 新增 Skill · review-platform

**原因：** 团队 AI 代码评审平台（`opencode.jubaozan.cn`）此前只能通过网页操作，Agent 无法定位评审任务、读缺陷证据或提交反馈，修复后也无法自查平台结论。实测 389 个任务确认平台以 **MR** 为评审单位（`REVIEW` 全部带 `mrIid`，`SCAN` 为单 ref 全库且不可靠），据此把触发路径、查询链路、15 个 MCP 工具与语义边界沉淀为技能。

**改动：**
- 新增 `review-platform/SKILL.md`：核心模型、三条触发路径、四步查询链路、工具速查、语义边界、反馈提交规则、已知失败模式、接入与探测命令
- `docs/skill-flow.md`：横切技能表新增 `review-platform` 行，技能总数 22 → 23
- 用户级 `~/.omp/agent/AGENTS.md`：收尾路由段新增「提 MR 后评审跟进」一行

**影响：**
- Agent 可在提 MR 后按分支 / SHA 定位评审任务、读缺陷与门禁结论、提交误报反馈、请求重评
- 硬约束：`RESOLVED` / `ACCEPTED` / `READY` / `REUSED_*` / 反馈 `SAVED` 等一律不得解读为「已修复 / 已通过 / 门禁已放行」
- 依赖本地 MCP 配置（`~/.omp/agent/mcp.json` 的 `review-platform` 条目），未配置或未重启 session 时工具不可见
